# Fluglabbet

En bananfluga (Jaffar) i 3D som ser två bilder genom facettögon och lär sig, via en förenklad hjärnkrets inspirerad av FlyWire-kopplingskartan, att gå till bilden med mest vitt.

- Öppna `index.html` i en webbläsare, eller besök GitHub Pages-länken.
- Ladda upp egna bilder för att se vad flugan uppfattar som ljust och mörkt.

Byggd med three.js (laddas från cdnjs/jsDelivr).
